Admin

Connect to GitHub

Paste your GitHub access token to manage photos. It is saved only in this browser and is never put on the website.

How do I get a token? (one time, about 2 minutes)
  1. Open GitHub → New fine-grained token (sign in if asked).
  2. Name it Website admin and set Expiration to a date you like (for example 1 year).
  3. Under Repository access, choose Only select repositories and pick KarolPasko.github.io.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above.

Don't share the token. If it ever leaks, delete it on that GitHub page and make a new one.
