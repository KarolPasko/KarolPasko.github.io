Admin

Connect to GitHub

Paste your GitHub access token to manage photos. It is saved only in this browser and is never put on the website.

How do I get a token? (one time, about 2 minutes)
  1. Open GitHub → New fine-grained token (sign in if asked).
  2. Name it Website admin and set Expiration to a date you like (for example 1 year).
  3. Under Repository access, choose Only select repositories and pick KarolPasko.github.io.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above.

Don't share the token. If it ever leaks, delete it on that GitHub page and make a new one.

      Add photos and videos to a show, or start a new one.

      Drag photos or videos here or click to choose

      Any photo works, including iPhone HEIC. Photos are turned into JPEGs and shrunk if needed so the site stays fast. Videos go up as they are, up to 50 MB each (about a minute of phone video). MP4 plays in every browser.

      Already on the site

      The photos at the top of the lighting page, and your About photo.

      Projects

      Each project gets its own log page. Untick Taking new entries to keep a log readable but stop new feedback.

      Log connection

      Connected. Entries are kept in a Google Sheet called KLD developer log in your Google Drive.

      The logs need a small free Google Apps Script to take in entries and email you. It only takes a few minutes, once.

      How to set it up
      1. Sign in to Google with the account you want to own the log, then open Apps Script → New project.
      2. Delete what's in the editor, click and paste it in. Click the save icon.
      3. In the bar at the top pick setup and press Run. Google asks for permission: choose your account, then Advanced → Go to project (unsafe) → Allow. It says unsafe only because you wrote the script yourself rather than Google checking it.
      4. Click Deploy → New deployment, click the cog and pick Web app. Set Execute as to Me and Who has access to Anyone, then Deploy.
      5. Copy the Web app URL (it ends in /exec), paste it below and click Save.

      If you change the script later, use Deploy → Manage deployments → edit → New version so the URL stays the same.

      Changes go live on the website a minute or two after you save them.
