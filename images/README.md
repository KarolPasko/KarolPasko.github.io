# Project photos

Each project has its own folder here. Every photo you put in a folder shows up on the website automatically, however many there are.

- **Add photos:** open the project's folder on GitHub, click **Add file → Upload files**, drag your pictures in, and click **Commit changes**. The site updates within a minute or two.
- **Order:** photos are shown in filename order (`1.jpg`, `2.jpg`, … `10.jpg`). The first one is the cover on the project card.
- **Formats:** `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`. Smaller files load faster, so aim for under about 1 MB each.
- **New project:** create a new folder here (for example `images/lionking/`), then add an entry with `folder: "lionking"` to the `projects` list at the top of `projects.js`.
