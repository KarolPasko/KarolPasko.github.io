# Presentations

PowerPoint files here are shown as clickable slides on the Education page.

- `lancaster-project.pptx`: the Lancaster project
- `uksdc.pptx`: the UK Space Design Competition presentation

Upload a file with exactly one of those names (GitHub: **Add file → Upload files**) and it appears on the site automatically. To add another presentation, upload it here and add `<div class="slides" data-file="presentations/your-file.pptx"></div>` where you want it in `education.html`.
