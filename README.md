# Karol Pasko Technical

Website for Karol Pasko Technical, a freelance lighting, sound, AV and technical production service. Hosted on GitHub Pages at https://karolpasko.github.io.

Plain HTML, CSS and JavaScript with no build step. The main page is `index.html`, which links to the lighting site (`technical.html`) and the education page (`education.html`). Edit those files for page text, and the `projects` list at the top of `projects.js` to add or change portfolio work. Project photos go in `images/<project>/`; see `images/README.md`.
